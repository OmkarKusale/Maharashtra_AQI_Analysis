# 🌍 Maharashtra Air Quality Analysis 2025

## Project Objective

The objective of this project is to analyze Air Quality Index (AQI) trends across 5 major cities in Maharashtra and identify city-wise, monthly, and quarterly air quality patterns.

## Dataset Used

- [📊 AQI Dataset](https://github.com/OmkarKusale/Maharashtra_AQI_Analysis/blob/main/data/AQI%20SUMMARY.xlsx)

## Questions (KPIs)

- What is the overall average AQI?
- Which city has the highest average AQI?
- Which city has the lowest AQI?
- How does AQI change across different months?
- Which quarter has higher AQI levels?
- How does AQI compare across different cities?

## Dashboard

- [📈 Power BI Dashboard](dashboard/Maharashtra_AQI_Analysis_2025.pbix)

## Process

- Collected AQI data for 5 major cities in Maharashtra.
- Cleaned, organized, and merged the data using Microsoft Excel.
- Calculated monthly average AQI values.
- Created Month Number and Quarter columns for proper time-based analysis.
- Imported the final dataset into Power BI.
- Used Power Query for data transformation.
- Created DAX measures and KPI cards.
- Built an interactive dashboard with charts, slicers, and a quarterly AQI heatmap.

## Project Insights

- Pune recorded the highest average AQI among the analyzed cities.
- Thane recorded the lowest average AQI.
- AQI levels varied across different cities, months, and quarters.
- Monthly and quarterly analysis helped identify air quality and seasonal patterns.
- The heatmap makes it easy to compare AQI across cities and quarters.

## Decision-Making Impact

- Helps identify cities with higher pollution levels that may require greater attention.
- Helps understand seasonal pollution patterns and high-risk periods.
- Supports better allocation of air quality monitoring and pollution-control efforts.
- Makes city-wise air quality comparison easier for decision-makers.

## Tools Used

- Microsoft Excel
- Power Query
- Power BI
- DAX

## Conclusion

This analysis provides a clear view of air quality trends across 5 major cities in Maharashtra during 2025. The dashboard helps compare AQI levels across cities, months, and quarters, making it easier to identify pollution patterns and support data-driven decision-making.
